# Candidate Ranker UI

## Build

```sh
npm install
npm run build
```
This compiles `App.jsx` into `app.bundle.js` using Babel.

## Preview locally

After building, start a simple HTTP server and open `index.html` in your browser:

```sh
npx http-server .
# or
python3 -m http.server
```

Then navigate to the served URL (default is `http://localhost:8080`).
